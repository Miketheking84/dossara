# Klik-flowovi i ponašanje sistema

## 1. Today → obaveza

```text
Klik na ročište
→ otvara Matter Cockpit / Sud
→ selektuje konkretan događaj
→ dostupno: dokument, izmena, završetak
```

```text
Klik na zadatak
→ otvara desni Task panel
→ dostupno: završi, promeni rok, otvori predmet, AI rad
```

```text
Klik na predmet bez sledećeg koraka
→ otvara Matter Cockpit / Pregled
→ fokus na polje Sledeći korak
```

## 2. Novi upit

### Povezivanje sa postojećim predmetom

```text
Upit
→ Poveži sa postojećim predmetom
→ izbor predmeta
→ preview destinacije
→ potvrda
→ kopiranje emaila/priloga u 01 ULAZ
→ chronology/document register update
→ otvara Matter Cockpit
```

### Novi predmet

```text
Upit
→ Pripremi novi predmet
→ prepopunjena forma
→ Conflict Check Lite
→ korekcije korisnika
→ potvrda
→ atomsko kreiranje foldera i kontrolnih fajlova
→ kopiranje ulaza
→ početni zadaci
→ Matter Cockpit
```

### Nedovoljno podataka

```text
Upit
→ Zatraži dodatne podatke
→ Email workflow
→ nacrt
→ copy/open Outlook
→ ručno označavanje kao poslato
→ intake status Čeka odgovor
```

## 3. Client Profile

```text
Klik Otvori folder klijenta
→ Windows Explorer
```

```text
Klik Novi predmet
→ New Matter forma sa unapred izabranim klijentom
```

```text
Klik Pripremi email
→ Email workflow sa unapred izabranim klijentom/kontaktom
```

## 4. Matter Cockpit

```text
Klik Ažuriraj sledeći korak
→ inline editor ili mali panel
→ validacija
→ atomski update command-center.md
→ rebuild matter index
```

```text
Klik dokument
→ otvara originalni fajl
```

```text
Klik Pokreni AI rad
→ AI workflow sa unapred izabranim predmetom
```

```text
Klik Pripremi email
→ Email workflow sa unapred izabranim predmetom
```

## 5. Sudski događaj

```text
Novi događaj
→ kratka forma
→ potvrda
→ court-events zapis
→ court-calendar.md update
→ Master indeks update
```

```text
Prepoznat događaj iz dokumenta
→ PENDING_REVIEW
→ prikaz izvora i pronađenog teksta
→ Potvrdi / Izmeni / Odbaci
```

Ako nema izričitog budućeg datuma, događaj se ne predlaže.

## 6. AI rad

```text
Izbor workflowa
→ izbor predmeta/dokumenata
→ dodatni kontekst
→ generisanje prompta
→ copy/save/open ChatGPT ili Claude
→ opcioni unos rezultata
→ status Čeka pregled
→ pregled/odobrenje
```

## 7. Pravne promene

```text
Detalj promene
→ poveži sa klijentom
→ kreiraj zadatak ili client alert
→ evidentiraj status praćenja
```

## 8. Arhiva i Trash

```text
Arhiviraj predmet
→ prikaz pune putanje
→ potvrda
→ premeštanje u 05 ARHIVA/KLIJENT
→ status ARCHIVED
```

```text
Premesti u Trash
→ dvostruka potvrda
→ 05 ARHIVA/_TRASH
→ moguć Restore
```

Trajno brisanje je dostupno samo iz `_TRASH` uz upisivanje naziva predmeta.
