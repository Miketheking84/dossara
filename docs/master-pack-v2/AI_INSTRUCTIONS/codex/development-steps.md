# Development Steps

Za svaku fazu:

1. Pročitaj Master Spec i spec funkcije.
2. Pregledaj postojeći kod i git status.
3. Napiši kratak plan i identifikuj rizike.
4. Implementiraj samo dozvoljeni scope.
5. Dodaj validaciju, prazna stanja i greške.
6. Dodaj ili ažuriraj testove.
7. Pokreni lint/build/test.
8. Pokreni aplikaciju i proveri ključni workflow.
9. Prikaži listu izmenjenih fajlova i rezultate testova.
10. Sačekaj funkcionalnu proveru korisnika pre commit-a.
