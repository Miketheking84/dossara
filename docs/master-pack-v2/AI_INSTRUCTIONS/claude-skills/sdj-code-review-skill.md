# SDJ Code Review Skill

Svrha: nezavisni pregled Codex izmene.

Proveriti:

- scope creep;
- path traversal i pisanje izvan workspacea;
- atomsko pisanje i rollback;
- destruktivne file operacije;
- stabilne ID/schema migracije;
- rebuildability indeksa;
- dupliranje izvora istine;
- server/client granice u Next.js;
- tipove, validaciju i error handling;
- UI prazna/loading/error stanja;
- pristupačnost;
- da nema API ključeva, upload logike ili eksternih poziva;
- lint/build/test rezultate.

Izlaz: kritično, visoko, srednje, nisko; precizan fajl i predlog ispravke.
