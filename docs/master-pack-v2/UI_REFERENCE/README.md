# UI Reference Prototype

Otvoriti `index.html` u browseru.

Ovo je:

- funkcionalna mapa ekrana;
- referenca za sidebar, topbar, liste, tabove i prazna stanja;
- demonstracija principa „jedan ekran — jedna svrha“.

Ovo nije produkciona aplikacija i nema stvarne file-system operacije.

Codex treba da implementira dizajn unutar postojećeg Next.js projekta, koristeći stvarne podatke i server-side servise.
